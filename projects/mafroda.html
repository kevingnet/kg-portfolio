Traceability — Americas

Current · Regional traceability lead · Live Demo

Lead traceability systems across the Americas. Apply AI on the engineering side — developer tooling, codebase modernization, and AI-assisted improvements to traceability projects and delivery workflows.

Traceability platform (FSMA 204). A .NET 9 platform that follows fruit from bin to shipment on MAF sorting lines and produces the records U.S. food-traceability rules require. Parts of it, including the operator display app, run in production at 4 packhouse sites.

  • ASP.NET Core server with SignalR, WPF operator apps and SQL Server; five layers enforced by architecture tests
  • Live fruit-flow graph from OMRON PLC counters (UDP and OPC UA) and integration with Orphea sizing, printers and ERP
  • FSMA 204 critical tracking events, a 28-rule compliance engine, FDA sortable spreadsheet, recall dossier and GS1 EPCIS 2.0 export
  • Digital twin and device simulators; ~3,700 automated tests; 68 projects; Windows installer

Outlet display: in production

The part of the platform packers see. A screen over each pair of outlets shows what to pack into the next box, counts cases against the order, and turns red when something goes wrong. It runs in production at packhouse sites; a live demo runs in the browser.

OpenCV Performance

SIMD · Buffer pre-allocation · Production sorters

Optimized OpenCV image-processing paths on production fruit sorters using SIMD intrinsics and an allocation strategy that pre-allocates buffers at startup.

Result: reduced runtime memory footprint and buffer churn during high-throughput sorting operations on the line.

Python Fleet Installer

ORPHEA Operations Framework · Python · YAML · WinRM

Designed and built the MAF Silent Install / ORPHEA operations framework: a layered Python system that provisions fruit-sorting clusters from YAML configuration.

  • Multi-tier architecture: high-level modules, operation objects, and support layer (WinRM, PSRP, OpenSSH, PsExec, WMIC, netsh)
  • Remote handling of large installer payloads (~10 GB), decompression, and end-to-end software deployment on Orphea, Engine, and cluster hosts
  • GUI (run_gui.py) and batch runners for field engineers; script catalog and per-operation YAML configs
  • Documented in Software Architecture Document, Functional Specifications, and Framework.md (installer.doc)

UiSettingsEditor

C# · WinForms · JSON · Figma palettes

Desktop tool for theming the outlet display above: it edits the display’s ui_settings.json, so a site can match its colors without touching code.

  • Loads and saves JSON appsettings for skin, outlet, and message styling
  • Figma-integrated color palette editor with live swatches (container, label, font, border, clock, message stroke/shadow)
  • Validates combinations and syncs palette slots for article / outlet configurations

Stack: .NET WinForms, System.Text.Json, custom color-swatch controls.
