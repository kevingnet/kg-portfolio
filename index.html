How I use AI in engineering

AI coding agents, with rules

The MAF RODA traceability platform is built with AI coding agents (Claude Code and Codex) working from written project rules for architecture, naming and testing, so their output follows the same design as the rest of the codebase.

Guardrails that catch mistakes

58 automated checks guard the codebase: SQL contracts against a live database, duplicate code, swallowed errors, UI contrast, and docs that no longer match the code. Each check is proven against a known-bad example.

Tests as the safety net

About 3,700 automated tests, plus architecture tests that fail the build when code crosses a layer boundary, hold AI-written and hand-written code to the same bar.

AI in the product too

ML.NET anomaly detection and packout forecasting in the traceability analytics, and AI-assisted tooling and codebase modernization across MAF RODA’s traceability projects.
